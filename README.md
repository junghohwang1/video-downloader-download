# 동영상 다운로더 내려받기

동영상 다운로더 설치 파일(안드로이드 · Windows PC)을 올려 두는 곳입니다. 광고가 없습니다.

## ⬇ 최신 버전 받기
- **안드로이드:** [videodownloader.apk](https://github.com/junghohwang1/video-downloader-download/releases/latest/download/videodownloader.apk) → [설치 방법](#설치-방법-안드로이드--삼성-갤럭시-기준)
- **Windows PC:** [VideoDownloader-Setup.exe](https://github.com/junghohwang1/video-downloader-download/releases/latest/download/VideoDownloader-Setup.exe) → [설치 방법](#설치-방법-windows-pc)
  (회사 PC 등에서 MSI 가 필요하면 [VideoDownloader.msi](https://github.com/junghohwang1/video-downloader-download/releases/latest/download/VideoDownloader.msi))

## 주요 기능
- 탭 브라우저에서 영상을 재생하면 오른쪽 아래 다운로드 버튼으로 받기 (mp4, HLS 등)
- 유튜브 영상 화질 선택 다운로드 (최대 1080p, 음성만 M4A), 한국어 자막 함께 저장
- 자막 만들기: 영상의 말소리를 인식해 한국어 자막 생성(외국어는 번역)
- 광고 차단(광고 서버·광고 칸·유튜브 영상 광고)
- 일시정지·이어받기, 진행 상태·완료 목록, 내장 플레이어
- 안드로이드: PIN 으로 잠그는 비공개 폴더, 외국어 페이지 번역, 앱 안 업데이트

## 설치 방법 (안드로이드 · 삼성 갤럭시 기준)

플레이 스토어 밖에서 받은 앱은 휴대폰이 여러 번 막습니다. 최신 안드로이드일수록 단계가 많습니다. 삼성 갤럭시(One UI 6~7) 기준이며, 기기마다 메뉴 이름이 조금 다를 수 있습니다. **화면에 나오는 문구를 보고 해당 단계를 따라 하세요.** (안드로이드 10 이상 필요)

### 1) 파일 받기
- 받은 링크를 누르면 `videodownloader.apk` 를 내려받습니다.
- 「이 유형의 파일은 기기를 손상시킬 수 있습니다」·「유해할 수 있는 파일」이라고 물으면 **「다운로드」**(또는 「무시하고 다운로드」)를 누릅니다.
- 카카오톡 안에서 받아지지 않으면 화면 오른쪽 위 **⋮ > 「다른 브라우저로 열기」**를 누른 뒤 다시 받습니다.

### 2) 파일 열기
- 다 받으면 화면 아래 **「열기」**를 누릅니다.
- 지나쳤으면 알림창의 다운로드 완료 알림을 누르거나, **「내 파일」 앱 > 다운로드 > videodownloader.apk** 를 누릅니다.

### 3) 「자동 차단기가 … 앱 설치를 차단했습니다」가 나오면
- 삼성의 자동 차단기(One UI 6 이상)가 스토어 밖 앱 설치를 막은 것입니다.
- **설정 > 보안 및 개인정보 보호 > 자동 차단기 > 끄기**. 그다음 2)부터 다시 합니다.

### 4) 「보안을 위해 휴대전화에서 이 출처의 알 수 없는 앱을 설치할 수 없습니다」가 나오면
- **「설정」**을 누르고 **「이 출처 허용」**(또는 「허용」)을 켠 뒤, 뒤로 돌아와 **「설치」**를 누릅니다.
- 이 허용은 파일을 연 앱마다 따로입니다. 카카오톡으로 열었는지, 인터넷·Chrome·내 파일로 열었는지에 따라 그 앱을 켜야 합니다.
- 직접 켜는 곳: **설정 > 애플리케이션 > 오른쪽 위 ⋮ > 특별한 접근 > 출처를 알 수 없는 앱 설치 > 해당 앱 켜기** (기종에 따라 설정 > 보안 및 개인정보 보호 > 기타 보안 설정 > 출처를 알 수 없는 앱 설치)

### 5) 「Play 프로텍트」 안내가 나오면
- 「앱을 스캔하여 보안 위협이 있는지 확인하시겠습니까?」 → **「스캔하지 않고 설치」**(또는 「앱 스캔」 후 설치).
- 「안전하지 않은 앱 차단됨」 → **「세부정보 더보기」 > 「무시하고 설치」**. 스토어에 없는 앱이면 흔히 뜨는 경고입니다.

### 6) 「설치」 > 「열기」
- 설치가 끝나면 「열기」로 시작합니다. 홈 화면이나 앱 목록에 「동영상 다운로더」가 생깁니다.

### 7) 설치 후
- 4)에서 켠 허용은 다시 꺼도 됩니다.
- 자동 차단기를 다시 켜면 보안은 좋아지지만, **새 버전 설치도 막힙니다.** 업데이트할 때만 잠시 꺼 주세요.
- 1.1.0부터는 새 버전이 나오면 앱을 켤 때 알려 주고, 앱 안에서 바로 업데이트됩니다(받은 파일·설정은 그대로).
- **1.0.x 를 쓰고 있었다면:** 1.1.0은 서명키가 바뀌어 기존 앱 위에 설치되지 않습니다. 남길 영상을 앱의 「갤러리로 내보내기」로 옮긴 뒤, 기존 앱을 지우고 설치하세요(앱을 지우면 앱 안에 저장된 영상도 지워집니다).

## 설치 방법 (Windows PC)

Windows 10·11 64비트에서 동작합니다.

### 1) 파일 받기
- 위의 [VideoDownloader-Setup.exe](https://github.com/junghohwang1/video-downloader-download/releases/latest/download/VideoDownloader-Setup.exe) 를 누릅니다(약 120MB).
- 브라우저가 「일반적으로 다운로드되지 않는 파일」이라고 막으면 **「⋯」 > 「유지」**(크롬은 **「계속」**)를 누릅니다.

### 2) 설치 파일 실행
- 받은 파일을 실행합니다.
- **「Windows의 PC 보호」** 파란 창이 뜨면 **「추가 정보」 > 「실행」**을 누릅니다. 코드 서명 인증서가 없는 프로그램이라 뜨는 경고입니다.
- 설치 위치를 묻는 화면은 그대로 **「다음」**을 누르면 됩니다(관리자 권한 없이 내 계정에만 설치됩니다).
- 설치가 끝나면 시작 메뉴와 바탕 화면에 「VideoDownloader」가 생깁니다.

### 3) 처음 실행
- 처음 한 번 내장 브라우저 구성 요소(약 100MB)를 받습니다. 진행 막대가 끝날 때까지 기다리세요.
- 「브라우저 설치를 마쳤습니다. 앱을 다시 시작해 주세요」가 나오면 창을 닫고 다시 실행합니다.

### 4) 쓰는 법
- 왼쪽 **「브라우저」**에서 영상 페이지를 열고, 오른쪽 아래 다운로드 버튼(감지된 영상 개수 표시)을 누릅니다. 영상 링크를 우클릭해 「이 영상 다운로드」도 됩니다.
- 받은 파일은 **동영상 폴더 > VideoDownloader** 에 저장됩니다(설정에서 바꿀 수 있음). 「완료」 화면의 「저장 폴더」로 바로 열 수 있습니다.
- 「완료」 화면의 **「자막 만들기」**를 누르면 한국어 자막(.srt)을 영상 옆에 만듭니다. 처음 한 번 음성 인식 프로그램·모델(약 200MB)과 ffmpeg(약 110MB)를 받습니다.
- 일부 사이트 영상은 내장 브라우저에서 재생되지 않습니다(H.264 형식). 안내가 뜨면 **「기본 브라우저로 보기」** 또는 **「다운로드해서 보기」**를 누르세요.
- 창을 닫으면 완전히 종료됩니다. 받는 중에 닫으면 트레이(작업 표시줄 오른쪽 아래)에서 마저 받고, 끝나면 스스로 종료합니다.

### 5) 업데이트·삭제
- 새 버전은 같은 링크에서 받아 설치하면 덮어 설치됩니다(받은 파일·목록은 그대로).
- 삭제: **설정 > 앱 > 설치된 앱 > VideoDownloader > 제거**. 받은 영상은 지워지지 않습니다.

## 이용 안내
- 저작권이 있는 콘텐츠는 권리자의 허락 없이 내려받거나 배포하지 마세요. 각 사이트의 이용약관을 따라야 합니다.
- 유튜브 기능은 오픈소스 [NewPipe Extractor](https://github.com/TeamNewPipe/NewPipeExtractor)(GPL-3.0)를 사용합니다. 앱 소스는 [junghohwang1/videodownloader](https://github.com/junghohwang1/videodownloader) 에 공개되어 있습니다.
